# Nhật ký sử dụng AI (Prompt Log)

Dưới đây là một số prompt đã được sử dụng với vai trò trợ lý thiết kế và phân tích kỹ thuật:

1. **Prompt Phân tích lỗi cũ (Brainstorming):**
   *"Khi tôi cần một bố cục mà một phần tử con (Child) phải chiếm chính xác 2 hàng và 2 cột (span 2 rows, 2 columns) đan xen với các phần tử nhỏ khác, tôi nên chọn CSS Grid hay Flexbox? Tại sao Flexbox lại chật vật với yêu cầu này?"*

2. **Prompt Bootstrap Logic (Phản biện logic):**
   *"Trong Bootstrap 5, sự khác biệt giữa lớp col-sm-4 và col-md-4 là gì? Tại sao tôi nên dùng Bootstrap thay vì tự viết CSS Grid cho một phần tử đơn giản như 3 cột Bảng giá?"*

3. **Prompt CSS Grid Bento (Pair-Programming):**
   *"Hãy cho tôi xem một cú pháp CSS Grid đơn giản (sử dụng grid-template-areas hoặc span) để tạo một layout dạng Bento Box: có 1 hình vuông lớn bên trái chiếm 2x2, và 2 hình vuông nhỏ bên phải."*

4. **Prompt Mobile Navbar (Testing):**
   *"Làm thế nào để sử dụng thuộc tính flex-wrap: wrap trong Flexbox kết hợp với CSS để Navbar trên điện thoại tự động đẩy các menu xuống dòng dưới mà không che khuất Logo?"*

5. **Prompt mở rộng về Gap (Tuning):**
   *"Sự khác biệt khi sử dụng thuộc tính gap trong cả CSS Grid và Flexbox so với việc sử dụng margin lộn xộn là gì? Nó giúp ích gì cho cấu trúc HTML trong tình huống này?"*
